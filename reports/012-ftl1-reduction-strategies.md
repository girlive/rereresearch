## Executive Summary

```
FTL1蓄積 → Fe³⁺蓄積 → ATP合成障害 → 海馬ニューロン老化 → 認知機能低下

★ 老齢マウスでFtl1ノックダウン → 認知機能が若年レベルに回復（確認済み）
```

**介入の3層構造**:

| 層 | アプローチ | 現在地 |
|----|-----------|--------|
| **最前線（実験的）** | FTL1遺伝子サイレンシング（ASO/CRISPR/shRNA） | 前臨床（マウス） |
| **中間（臨床応用中）** | 鉄キレート剤（デフェリプロン） | 神経フェリチノパチーでフェーズ2 RCT進行中 |
| **今すぐできる** | 生活習慣（運動・食事制限・NADH前駆体） | 間接的・補助的エビデンス |

> **重要な警告**: 汎用的な鉄キレート療法（デフェリプロン）はAD・PDでは症状を**悪化**させた実績あり（後述）。FTL1特異的な制御が鍵。

## 1. 直接的アプローチ：FTL1発現を抑制する

### 1.1 遺伝子サイレンシング（shRNA / CRISPR）— 現在最も有力[^1]

**Nature Aging 2025（PMID: 40830655）の実験内容:**

```
老齢マウス（18〜24ヶ月）
  ↓ AAV-shRNA を海馬に投与
  （シナプシン-1プロモーター → ニューロン特異的発現）
  ↓
Ftl1が低下
  ↓
シナプスマーカー回復（NR2A、AMPA受容体、シナプシン）
  ↓
新規物体認識・Y迷路テストで認知機能が**若年レベルに回復**
```

- **ステータス**: 前臨床（マウス in vivo）
- **次のステップ**: 霊長類への外挿、BBB通過型デリバリー開発、Phase I射程は2030年以降

### 1.2 アンチセンスオリゴヌクレオチド（ASO）[^2]

- 脊髄性筋萎縮症（Spinraza）・ALS（Tofersen）でASO治療が実臨床入り済み
- ApoEペプチドなどを用いたBBB透過性ASOの技術基盤が整備中
- FTL1特異的ASOは**探索段階**。理論的には合理的な次のステップ

### 1.3 IRP-IREシステムを利用した翻訳抑制[^3]

```
FTL mRNA の5'UTR にはIRE（Iron Response Element）が存在

低鉄状態 → IRP1/IRP2がIREに結合 → FTL1翻訳を抑制
                     ↑
           eIF3も独立して翻訳を抑制（鉄非依存的）

→ 細胞内鉄を適切に下げることで自然にFTL1翻訳が抑制される
```

- IRE阻害薬（IRP結合を模倣）の探索が神経変性疾患文脈で進行中
- ただしFTL以外のIRE含有mRNA（APP、α-シヌクレインなど）にも影響するため選択性が課題

## 2. 鉄代謝介入：鉄を操作してFTL1蓄積を防ぐ

### 2.1 デフェリプロン（経口鉄キレート剤）— 唯一BBBを通過できる承認薬[^4]

```
デフェリプロン
  低分子量・脂溶性・中性電荷
  → BBB通過可（現行承認鉄キレート剤で唯一）
  → 脳内の不安定鉄をトランスフェリンに転移
  → 過剰鉄を安全に除去（貧血リスク低）
```

**神経フェリチノパチーへの使用実績:**
- 4症例（Movement Disorders 2022）: 早期症例（罹病4年未満）で11年超の安定化達成
- "治療開始が早いほど効果が高い"

**DefINe試験（2024年〜、進行中）:**
- 神経フェリチノパチー専用Phase 2 RCT（ISRCTN15571700）
- ケンブリッジ大学 / LifeArc資金（75万ポンド）
- 40名 / 12ヶ月 / 7T MRIで脳内鉄追跡
- 結果は2025〜2026年に予定

> **⚠️ 重大な警告**: AD（JAMA 2025）とPD（NEJM 2023）では認知・運動機能が**悪化**。FTL1過剰蓄積が原因の脳老化に特化した使用でのみ有効性を期待すべき。

### 2.2 経鼻デフェロキサミン[^4]

- 通常はBBBを通過しないが、**嗅神経・三叉神経経路**経由で脳内到達可能
- ADトランスジェニックモデルで記憶欠損改善
- 臨床試験は初期段階

### 2.3 デフェラシロクス（経口）— 全身フェリチン低下に有効だが脳には届かない

- 5年追跡で血清フェリチン中央値706 ng/mL低下（Blood 2011）
- **BBB通過性が低い**ため、脳内FTL1には直接効かない
- 全身性鉄過剰（輸血性など）が背景にある場合の補助的使用に留まる

### 2.4 カロリー制限・食事性鉄制限[^5]

- 老齢アカゲザルでカロリー制限により大脳基底核・黒質での**鉄蓄積が有意に減少**（J. Neurosci. 2012）
- 老齢マウスで食事制限が黒質での「鉄恒常性解離」（鉄増加にもかかわらずフェリチンが上昇しない異常）を是正（Aging 2016）

## 3. フェリチノファジー：FTL1を分解して除去する

### 3.1 NCOA4経路の活性化[^6]

```
NCOA4（選択的オートファジー受容体）
  ↓ FTH1サブユニットに結合
フェリチン24量体（FTL + FTH1）を
オートファゴソームへ輸送
  ↓
リソソームで分解 → 鉄を放出（再利用可能に）
```

**活性化する方法:**
- **鉄キレート剤で細胞内鉄を低下させる** → NCOAがHERC2から解放され安定化 → フェリチノファジー促進
- **mTOR阻害**（ラパマイシン等）→ フェリチノファジーを開始（2025年 CRISPRスクリーニング）
- GATE16/GABARAPL2-NCOA4相互作用の増強（探索段階）

> ⚠️ **副作用リスク**: フェリチン分解で遊離Fe²⁺が急増 → フェントン反応 → フェロトーシス（鉄依存性細胞死）の誘発リスク。神経細胞への適用は慎重に。

### 3.2 MMRi62（フェリチン分解誘導化合物）[^7]

- MDM2-MDM4標的として開発されたが、**NCOA4/FTH1のリソソーム依存的分解**を誘導
- 膵臓癌マウスモデルで遠隔転移を完全阻止
- **癌文脈では有望**だが神経保護の文脈での応用は未検討

## 4. NADH代謝介入：FTL1蓄積の悪影響を緩和する

### 4.1 NMN/NR — NADH補充 + リソソーム機能改善[^1][^9]

```
FTL1増加 → Fe³⁺蓄積 → ATP合成障害
                            ↑
                       NADH補充で補完可能
（in vitro でFTL1過剰発現の悪影響を完全抑制 — Nature Aging 2025）
```

**NMN（ニコチンアミドモノヌクレオチド）の追加的作用 — Life Science Alliance 2023:**

```
NMN投与
  ↓
リソソーム機能が改善（lysosomal biogenesis促進）
  ↓
フェリチノファジー（NCOA4経路）が活性化
  ↓
老化細胞での鉄蓄積が有意に減少
```

- **対象**: 老化マウス / in vitro 老化モデル
- **エビデンスレベル**: confirmed（動物・in vitro）

**NR（ニコチンアミドリボシド）— 2025年 MCI臨床RCT:**

- 軽度認知障害（MCI）患者に6ヶ月NR補充
- CSFバイオマーカー改善、認知機能テストで有意差（2025年報告）
- **エビデンスレベル**: likely（ヒト初期RCT、FTL1特異的ではない）

> ⚠️ FTL1への特異的効果はNAD補充の複合作用に含まれる可能性あり。FTL1単独標的としての効果は未証明。

### 4.2 スペルミジン（ポリアミン）[^9]

```
スペルミジン（天然ポリアミン / オートファジー誘導物質）
  ↓ 3週間補充
老齢者の筋肉サンプルでFTL蓄積が有意に減少（CMLS 2025）
  + mTOR非依存的オートファジー活性化
  + 抗炎症作用
```

- **ソース**: CMLS (Cellular and Molecular Life Sciences) 2025
- **含有食品**: 小麦胚芽、大豆、チーズ（熟成）、マッシュルーム
- **エビデンスレベル**: likely（ヒト観察 + 動物）

### 4.3 ラパマイシン（mTOR阻害）— 重要な逆説[^6]

> ⚠️ **逆説的リスク**: mTOR阻害によるオートファジー促進はフェリチノファジーを活性化することが期待されるが、**mTOR欠損はFBXL5-IRPシグナルを介してフェリチン蓄積を引き起こすことも確認されている**（2025年データ）。

```
ラパマイシン
  ↓
mTOR阻害
  ↓
[経路A] オートファジー促進 → フェリチノファジー → FTL分解 ✅
[経路B] FBXL5↓ → IRP安定化 → FTL mRNA翻訳抑制解除 → FTL蓄積 ⚠️
```

→ 純効果は細胞種・投与量・文脈による。神経細胞での長期使用データなし。

### 4.4 ビタミンE（α-トコフェロール）— APOE4保因者での特異的効果[^9]

- **APOE4保因者**でα-トコフェロール最高四分位群は認知機能低下速度が**16.4%遅い**（疫学研究）
- 機序: ビタミEの脂溶性抗酸化作用がFerroptosisを抑制
- **エビデンスレベル**: likely（観察疫学、RCTなし）

### 4.5 有酸素運動（Frontiers 2025より）[^8]

```
有酸素運動8週間
  ↓
ADマウスモデルでFTLが上方制御（Xc-/GPX4経路活性化）
  → フェロトーシス・脂質過酸化を抑制
  → 認知障害が改善
```

> ※ これはFTL1を**増やす**介入ではあるが、フェロトーシス文脈では保護的に作用。老化による**無秩序な**FTL1蓄積とは異なる生理的な鉄恒常性維持反応と解釈される。

### 4.6 NAC（N-アセチルシステイン）— 年齢依存的な限界[^9]

- 若いマウスではNACが酸化ストレス軽減に有効
- **老齢マウスでは無効**（GSSG/GSH比の改善なし）
- → 高齢者での抗酸化サプリとしての効果は限定的

## 5. 生活習慣・栄養・天然化合物

### 5.1 献血 / 瀉血（最も効果が大きい非薬物介入）[^10]

```
定期献血（400 mL / 回）
  ↓
血清フェリチンが約55%低下（複数回後）
  ↓
CSFフェリチンも低下（腰椎穿刺研究より）
  ↓
認知機能低下の進行速度と相関
```

- **CSFフェリチンが認知低下の予測因子**であることが確認されており（ランダム化比較試験ではなく観察研究）、献血による全身フェリチン低下が脳フェリチンに間接的に影響する可能性
- **実用性**: ✅ 今すぐ可能（献血基準を満たせば）、無料
- **注意**: 貧血傾向・閉経前女性では過剰なフェリチン低下リスク
- **エビデンスレベル**: confirmed（血清フェリチン低下）/ uncertain（脳FTL1特異的効果）

### 5.2 EGCG（緑茶カテキン）— BBB透過型の天然鉄キレート剤[^10]

```
EGCG（エピガロカテキンガレート）
  ↓ BBBを通過（脂溶性・低分子量）
脳内の遊離Fe²⁺/Fe³⁺をキレート
  ↓
IRP2が安定化・活性化
  ↓
FTL mRNA の5'UTR IRE に結合 → FTL1翻訳を抑制
```

- **IRP-IREシステムを天然化合物で活性化**できる点が他の鉄キレート剤と異なる
- 認知症予防文脈での観察研究でも一貫した関連
- **エビデンスレベル**: likely（in vitro + 疫学）
- **摂取目安**: 緑茶3〜5杯/日（EGCG約300〜500mg相当）

### 5.3 クルクミン（ターメリック）[^10]

```
クルクミン
  ↓ Fe²⁺/Fe³⁺の両方をキレート
IRP2を活性化 → FTL翻訳抑制
  ↓
FTLタンパク質レベルが低下
  （※ mRNAは上昇するが翻訳が抑制される「翻訳レベル制御」）
```

- **バイオアベイラビリティが問題**: 単独摂取では吸収率が非常に低い
- **改善策**: ピペリン（黒胡椒成分）との併用で吸収率が最大2000%向上
- リポソーム製剤・ナノ粒子化も有効
- **エビデンスレベル**: likely（in vitro）/ uncertain（ヒトFTL1への直接効果）

### 5.4 断続的断食（16:8 インターミッテント・ファスティング）[^10]

```
16:8 断食プロトコル（8時間の摂食窓）
  ↓ 数ヶ月継続
CSFフェリチン約28%低下（短期研究）
  + オートファジー誘導 → フェリチノファジー促進
  + インスリン感受性改善 → 炎症軽減 → 鉄代謝改善
```

- **エビデンスレベル**: likely（観察・短期介入）
- **実用性**: ✅ 今すぐ可能、費用ゼロ

### 5.5 鉄吸収抑制（食事性介入）[^5][^10]

| 化合物 | 鉄吸収抑制率 | 含有食品 | 摂取タイミング |
|--------|------------|---------|-------------|
| **タンニン酸** | 最大97% | 緑茶・紅茶・コーヒー・赤ワイン | 食事中 |
| **フィチン酸** | 86〜93% | 大豆・全粒穀物・豆類 | 食事中 |
| **シュウ酸** | 〜60% | ほうれん草・ナッツ | 食事中 |
| **カルシウム** | 〜30% | 乳製品 | 食事中 |

> 鉄吸収抑制剤は鉄が豊富な食品と**同時摂取**することで最大効果。食間での摂取は効果が薄い。

### 5.6 有酸素運動 — ヘプシジン-フェロポルチン軸の正常化[^8][^10]

```
有酸素運動（週150分以上）
  ↓
ヘプシジン（肝臓由来鉄調節ホルモン）の分泌パターン正常化
  ↓
フェロポルチン（鉄輸出タンパク質）の活性が最適化
  → 過剰な細胞内鉄の排出促進
  + イリシン分泌 → NLRP3インフラマソーム抑制 → 炎症性鉄代謝異常の改善
```

- **エビデンスレベル**: confirmed（動物）/ likely（ヒト間接エビデンス）

## 8. 重要な矛盾・警告

### ⚠️ 警告1: 汎用鉄キレートは逆効果になりうる

| 疾患 | デフェリプロンの結果 |
|------|-------------------|
| **神経フェリチノパチー** | ✅ 早期では11年超の安定化（Movement Disorders 2022） |
| **PKAN（NBIA）** | △ 成人発症型では改善、若年型では効果なし（Lancet Neurol. 2019） |
| **パーキンソン病** | ❌ 運動障害が**悪化**（NEJM 2023） |
| **アルツハイマー病** | ❌ 認知機能低下が**加速**（JAMA 2025） |

→ 脳内の鉄は一部がニューロン機能の維持に必要。汎用的な鉄低下は有害。
**FTL1という特定タンパク質を標的とした精密介入**が求められる。

### ⚠️ 警告2: FTL1ノックダウンで遊離鉄が増える逆説

```
FTL1を減らす
  ↓
鉄貯蔵能が低下
  ↓
細胞内遊離鉄（labile iron pool）が増加
  ↓
フェントン反応 → ROS産生 → 酸化ストレス増大
```

**Nature Aging 2025はこの逆説を実験的に否定**したが、投与量・対象細胞・疾患ステージによって有害にもなりうる。Dosing（投与量）の慎重な設定が必須。

### ⚠️ 警告3: FTL1の二面的役割

| 文脈 | FTL1の役割 |
|------|-----------|
| 老化した海馬ニューロン | 有害（認知低下の原因） |
| 急性脳虚血 | 保護的（NF-κB抑制で神経炎症緩和） |
| がん細胞 | 腫瘍促進・フェロトーシス抵抗性 |
| 炎症・敗血症 | 保護的（臓器障害を防ぐ） |

→ 脳老化の文脈でも「ニューロン特異的・老化特異的」な抑制が必要。
